# Findings from integrating the Academy UI

What was found while merging the learner-facing app (from `Narasimhat/Assured_Academy`, commit `4ab6f72`) into this repository and rebuilding its data from the real Design and QC engines. Each item says what was observed, how, and what was changed. Where a cause is inferred and not established, it says so.

## 1. The Design hand-off for HBB E7V has two defects

Observed on the engine design for HBB Glu7Val (`apps/academy-core/data/designs/HBB_E7V.engine.design.json`, built on `NG_059281.1`, one `+` strand guide). Both are reported by `tools/verify_designs_grch38.py` (47 checks across three designs: 45 pass, these 2 do not).

1. **The edit base is exported with role `blocking`, and no marker is flagged `intended`.** The base at design position 541 is the middle base of codon 7 (GAG to GTG). A codon translation of every marker, done independently of the export, shows it is the only amino-acid-changing change. The three silent changes at 533, 536 and 539 are labelled correctly.
2. **The guide's `offsetFromEdit` is -2, but cut minus edit position is -3** (cut 538, GRCh38-verified edit at 541). For the four APOE guides the two agree exactly.

Both appear only for the `+` strand guide design, which suggests one cause. A reading of `qcExport.js` found that the intended position is computed as `donorStart + desiredDiffIndexes`, which for this design lands on a base that is not changed. That points to the orientation of `desiredDiffIndexes`, but it is an inference from reading the code, not a confirmed cause. The symptom is certain.

**Consequence, tested.** Eight synthetic clones were generated for the HBB design (full donor, blocking changes only, heterozygous mixtures, edit on one allele and blocking-only on the other, unedited) and read by Assured QC twice: once with the file as exported, once with only the role of position 541 corrected. The output was identical in every compared column (`out/hbb_role_label_test.csv` in the change report). **Assured QC is not affected.** Code that reads `role` directly is: the Academy simulator and grader would treat the edit as a blocking change. `buildContext` now refuses an HDR design with no `intended` marker (three tests), and the UI data generator derives the intended marker from the codon change and records that it corrected the label.

Not changed: the Design engine. A fix pull request is available on request.

## 2. Assured QC against the lab's own calls on real traces

Ten real clones are shipped (five APOE R176C, five MYD88 knockout), matched to the lab's CSV by sha256 of each `.ab1`. `apps/academy-core/data/real_trace_qc/comparison.csv` is regenerated by `tools/compare_real_traces.py` from the engine output and the lab CSVs, with an explicit agreement rule.

| | clones | agree | lab pipeline gave no call | differ |
|---|---|---|---|---|
| APOE R176C | 5 | 5 | 0 | 0 |
| MYD88 KO | 5 | 4 | 1 | 0 |

The one clone without a lab call (MYD88 well A3) is read by the engine as compound heterozygous (a -79 bp and a second deletion) with moderate confidence. **This measures agreement with the lab's pipeline. It is not an independent genotype**, and a single Sanger read cannot show a large deletion on the other allele.

APOE needs the lab's real guides and variants. The repo's fixture design has different markers and calls the lab's "first choice" clones as blocking-only. A design reconstructed from the lab run manifest (two guides, three variants D172D, R176C, L177L; the ssODNs are reconstructed, not the lab's order sheet) reproduces all five lab calls. MYD88 was run in cut-discovery mode because the guides were not recorded.

## 4. Observations on the paper and on the tools

Offered for the author's judgement; none was changed.

- "650 uL of CloneR2 in 10 mL of StemFlex (1:20)": 650/10,000 is about 1:16.
- The mix volumes of Table 7 imply roughly 1:6.5 Cas9 to gRNA for a one-gRNA knockout (0.5 uL of 10 ug/uL Cas9 is about 31 pmol assuming 162 kDa; 2 uL of a 100 uM gRNA stock is 200 pmol). This is this report's arithmetic under those assumptions, and it differs from the "1:1.2 to 1:2" the old Academy text taught.
- Step 19 asks for primers amplifying 400 to 450 bp. The Design engine's amplicons for APOE and HBB are 470 and 485 bp.
- The teaching sketch finds an NGG site on the `-` strand 2 bp from the HBB edit (`GTAACGGCAGACTTCTCCTC`, PAM AGG) that the Design engine did not return. Why was not established; the engine may apply filters the sketch does not.
